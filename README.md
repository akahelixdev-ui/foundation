# Halim Hashi Foundation

Official website for the **Halim Hashi Foundation**, a family educational foundation based in Bangladesh dedicated to providing study kits, textbooks, board examination fee sponsorships, and classroom essentials to rural students.

Supported and primarily funded by [AKAHELIX INC.](https://akahelix.com/).

## Built With

- [TanStack Start](https://tanstack.com/start)
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
